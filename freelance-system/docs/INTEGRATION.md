# Интеграция с brain-v2

Этот пакет не дублирует хранилище — использует то, что уже развёрнуто
в `brain-v2` (Neo4j + Graphiti + существующий Postgres/pgvector).

## Что добавляется в Postgres

Новые таблицы из `db/schema.sql` (`jobs`, `applications`, `decisions`,
`outcomes`) создаются в той же базе, что и остальные проекты — просто
отдельная схема `freelance`, чтобы не пересекаться с данными других
направлений (контент-фабрика, Godot, сайты).

```sql
CREATE SCHEMA IF NOT EXISTS freelance;
```

## Что пишется в Graphiti

Не все данные — только значимые факты для few-shot генерации и анализа
паттернов:
- Успешные формулировки заявок (с меткой, под какой тип вакансии сработали)
- Причины отклонения/правки на каждой точке подтверждения
- Паттерны проблемных клиентов (red flags, подтверждённые исходом)

Сырые данные (весь текст всех вакансий, черновики) остаются в Postgres —
в Graphiti идёт только то, что нужно для рассуждения агента о "что сработало".

## Оркестрация

Как и в brain-v2: Claude Code + MCP-инструменты как основной оркестратор,
n8n — только триггеры (см. `n8n/triggers_README.md`). Скрипты в `scripts/`
вызываются Claude Code напрямую или через cron, не через визуальные
воркфлоу n8n.
