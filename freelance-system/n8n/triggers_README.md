# n8n в этой системе — только триггеры

По архитектуре brain-v2: n8n не участвует в принятии решений, только
запускает скрипты по событиям.

## Что настроить в n8n

1. **Cron-триггер** каждые 15-30 минут → `scripts/discover_jobs.py`
2. **Cron-триггер** сразу после discover → `scripts/score_job.py`
3. **Webhook/Cron** раз в день → `scripts/track_outcome.py --auto-check`
4. **Cron-триггер** раз в 21 день (см. `review_cadence_days` в конфиге) →
   `scripts/weekly_review.py`

## Что НЕ должно быть в n8n

- Никакой логики принятия решений (скоринг, генерация заявок, оценка
  объёма) — это делает Claude Code через прямые вызовы скриптов
- Никакой логики точек подтверждения — она в `config/confirmation_points.yaml`
  и обрабатывается самими Python-скриптами, не визуальными IF-нодами

Если вырастет необходимость в уведомлениях (например, "новая вакансия
требует подтверждения") — это нормальная роль для n8n: простой webhook
в Telegram/Slack, без бизнес-логики внутри самого воркфлоу.
